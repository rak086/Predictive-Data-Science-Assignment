# Predictive Data Science (PDA) - Case Study & Lab Assignments

This repository contains implementations of predictive modeling algorithms and case studies for the Predictive Data Science course.

## Contents

- **Q2**: Simple Linear Regression (`Q2_linear_regression.py`)
- **Q3**: Logistic Regression (`Q3_logistic_regression.py`)
- **Q4**: SVM and Decision Tree Classification (`Q4_svm_decision_tree.py`)
- **Q5**: Gaussian Naive Bayes Classification (`Q5_naive_bayes.py`)
- **Q6**: Market Basket Analysis with Apriori & Association Rules (`Q6_market_basket_analysis.py`)
- **Q7**: Breast Cancer Predictive Diagnosis in R (`Q7_breast_cancer_prediction.R`)
- **Q8**: HR Analytics Hourly Employee Demand Prediction in R (`Q8_hr_analytics_demand.R`)

## Requirements
- Python 3.x (`numpy`, `pandas`, `scikit-learn`, `mlxtend`, `matplotlib`)
- R 4.x
